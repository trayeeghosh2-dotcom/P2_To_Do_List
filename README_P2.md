📝 Project 02: Interactive To-Do List with LocalStorage

📌 About the Project

The Interactive To-Do List is a web-based task management application developed as part of the InternCircle Internship Program.

This project helps users manage their daily tasks easily. Users can add new tasks, mark tasks as completed, delete tasks, and save their tasks using LocalStorage.

The tasks remain saved even after refreshing or reopening the browser.

🎯 Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Save tasks using LocalStorage.
- Automatically load saved tasks.
- Simple and user-friendly interface.
- Responsive web design.
- Easy task management.

🛠️ Technologies Used

- HTML5 – For creating the webpage structure.
- CSS3 – For styling and designing the application.
- JavaScript – For adding interactive functionality.
- LocalStorage – For saving tasks in the browser.

🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the "list.html" file.
4. Right-click and select Open with Live Server.
5. The To-Do List application will open in your browser.
6. Start adding and managing your daily tasks.

💻 Requirements

- Visual Studio Code
- Web Browser (Google Chrome recommended)
- Live Server Extension
